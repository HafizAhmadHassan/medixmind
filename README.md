# MedixMind
*Created: 2025-08-15*

A **Next.js** web application deployed on Vercel, centered around a medical / wellness theme.

## Overview

MedixMind is built with **TypeScript** and includes **internationalization (i18n)** support for a multi-language experience. It focuses on wellness-related content and user flows.

## Features

- Next.js App Router application
- TypeScript throughout
- i18n / multi-language support
- Deployed on Vercel

## Tech Stack

Next.js, TypeScript, Tailwind CSS, Vercel.

## Status

Active web application.
